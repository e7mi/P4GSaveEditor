# P4G Save Editor

Persona 4 Golden (Steam)のセーブデータを編集する Windows用のGUIツールです。Rustで実装しており、配布物は単体のexeです。起動時にSteamのuserdataからセーブを探します。

## 動作環境

- Windows 10 / 11 (64bit)
- インストール作業は不要です

## 使い方

1. ゲームを終了します。
2. `P4G Save Editor.exe` を起動します。
3. 上部のスロット表示で編集するセーブを選びます。
4. 左のメニューから項目を選び、値を変更します。
5. `保存` を押します。保存前のファイルはセーブと同じフォルダの `backup` に自動で退避されます。
6. ゲームを起動してセーブを読み込みます。

Steamのセーブが自動で見つからない場合は、`フォルダ` を押して `...\1113000\remote` を選んでください。

## セーブデータの場所

通常は次の場所にあります。

```text
C:\Program Files (x86)\Steam\userdata\<SteamID>\1113000\remote
```

`dataXXXX.bin` と `dataXXXX.binslot` の組が 1 スロットです。編集するときは、この 2 ファイルがそろっている必要があります。

## 編集できる項目

| ページ | 内容 |
| --- | --- |
| 基本 | 名前、所持金、レベル、累計XP、HP/SP、プレイ時間、難易度、社交ステータス、現在のパーティ、実績カウンタ |
| 日付 | 現在の日付と時間帯、次に進む日付と時間帯 |
| 仲間 | メンバーのHP/SP、状態異常の解除、ペルソナ、装備の変更 |
| ペルソナ | 主人公の所持枠12個のレベル、ステータス、スキル |
| 全書 | 249枠の登録、初期化、解除、未登録のみの表示 |
| コミュ | 23枠のランクと好感度 |
| アイテム | 2559枠の所持数、全アイテムの一括追加と全削除、カテゴリと検索による絞り込み |
| ツール | チェックサムの再確認、バックアップと復元、別スロットへの複製、JSON書き出し |

数値は各項目のテキストボックスに直接入力し、最後に`保存`を押すと確定します。`詳細`をオンにすると、日付ページに内部日付（シリアル値）が表示されます。

保存時にはヘッダチェックサム、セーブMD5、スロットMD5を再計算します。

## 注意

- セーブの編集は自己責任で行ってください。大切なセーブは手動でもコピーしておくことを勧めます。
- ゲームを起動したまま保存すると、ファイルがロックされたり、ゲーム終了時に上書きされたりします。必ずゲームを終了してから編集してください。
- Steam Cloudを使っている場合、クラウド側のデータで上書きされることがあります。同期の競合が出たらSteamの状態を確認してください。
- 名前はセーブ内のShift-JIS領域とPC用のUTF-8領域の両方に書き込みます。長すぎる名前は切り詰められます。ゲーム内の表示が崩れた場合は、ゲーム側で一度保存し直してください。
- レベルと累計XPは独立した項目です。レベルだけを変えると、次のレベルまでの必要XPが合わないことがあります。
- アイテム、ペルソナ、スキルはゲーム内の日本語名で表示します。日本語名が取得できない未使用枠は`未使用`と表示されます。`詳細`をオンにすると、未使用のアイテムやペルソナも一覧に表示されます。
- 最大HP/SPはゲーム側の計算に依存します。上限を超える値を入れた場合、ゲーム内で補正されることがあります。
- 未署名のexeのため、初回起動時にSmartScreenの警告が出ることがあります。`詳細情報`から実行してください。

## ビルド

Rust 1.85 以降が必要です。

```powershell
cargo build --release
```

出力は `target\release\p4g-save-editor.exe` です。データはexeに埋め込まれるので、実行時に`assets`フォルダは要りません。

テストは次のコマンドで実行します。Steamのセーブが見つかる環境では、実際のセーブを一時フォルダに複製して検証します。見つからなければ検証は行われません。

```powershell
cargo test
```
